## 视频下载 tab 兼容抖音普通视频链接（commit d1f6726）
- 问题：`www.douyin.com/video/{id}` 普通视频页链接在下载 tab 里无法下载。原有 `extract_douyin_video` 只针对商品页（拦截 promotion/pack API + 只匹配 douyinvod.com）
- 实测结论：纯 requests 拿不到数据（抖音对无 JS 环境返回 body 为空的空壳页，ttwid cookie 也无济于事），必须 Playwright 渲染
- 方案：`extract_douyin_video` 重构为通用逻辑，返回 (url_list, err, referer)：
  1. 轮询等待 video 标签 src（普通视频页最可靠，含 douyinvod CDN 直链和 www.douyin.com/aweme/v1/play 签名接口）
  2. 网络捕获 douyinvod.com / aweme.snssdk.com / zjcdn.com / aweme/v1/play + promotion/pack（商品页）
  3. 点击/滚动触发懒加载后再试
  4. HTML 搜索 douyinvod 地址
- `_download_douyin`：候选 URL 逐个尝试；Referer 动态（视频页 douyin.com / 商品页 haohuo.jinritemai.com）；文件名用 `/video/{id}` 提取的视频 ID
- 实测：用户链接下载成功（42.5s/4.03MB），商品短链 v.douyin.com 回归通过（referer 正确走 haohuo）
- 注意：下载 tab 里抖音每个链接会独立 launch 一次 Chromium（约 10s/个），后续如批量需求可考虑复用共享浏览器

## 抖音分享短链兼容 + 预览片段拦截修复（commit fc55e22）
- 用户反馈分享文本形式：`4.69 复制打开抖音，看看【xxx】... https://v.douyin.com/c_NQt63onUI/ q@e.OK use:/ 08/04 :2pm`
- 预清洗 `extract_urls_from_text` 已验证能干净提取这种文本里的短链（中文/全角标点自动截断）
- **重大发现：抖音视频页 video 标签 src 加载时序**——加载初期是 douyinvod 直链（约 200KB 的 2~3 秒预览片段，HEVC 无音频），数秒后（约 t=9s）切换为 www.douyin.com/aweme/v1/play 签名接口（完整视频，H264+音频）。之前优先取 douyinvod 直链导致下载到 2.6s 预览片段
- 修复：① _extract_douyin_video_from_tag 优先返回 aweme/v1/play；② 轮询等待完整视频最多 16s，预览直链仅兜底；③ _download_douyin 下载后校验文件 <300KB 判定预览/异常，删除并换候选
- 实测：分享短链 → 58.9s/7.8MB 完整视频；普通视频页 4.03MB、商品短链 1.75MB 回归通过
- 三条链路全部验证：www.douyin.com/video/{id} / v.douyin.com 视频分享短链 / v.douyin.com 商品短链
