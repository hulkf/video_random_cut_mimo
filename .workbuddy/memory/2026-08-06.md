## V9: 性能优化——并发 + 硬件编码
- 需求：处理速度太慢，要求"按最高速度"设计提速方案
- 性能实测（30s 640x360 × 5份）：libx264顺序 8.33s → **NVENC并发3 = 1.33s（6.3x）**；libx264并发8 = 3.04s（2.7x）；**QSV 23.4s 更慢弃用**
- `core/video_fission.py`：
  - `fission_folder` 改为**并发执行**：ThreadPoolExecutor 展开全部 (视频×份) 任务并行跑；进度回调按"份"粒度（锁保护，并发安全）；失败聚合
  - 编码器自动探测 `_probe_encoder()`：NVENC（0.3s 试编码实测可用性）→ 不可用直接 libx264；`_test_hardware()` 实测；硬件失败回退软件重试（`fallback_to_software`）
  - 并发下中断：`_procs` 列表管理所有 ffmpeg 子进程，`request_stop()` terminate 全部；FissionStopped 从任务线程传播后 cancel 剩余
  - `default_workers()`：NVENC=3（session限制）/ 软件=min(核数,8)
  - 非中断失败也删除半成品文件
- `gui/video_fission_tab.py`：「裂变参数」加「并行任务:」SpinBox（0~16，0=自动，默认0），配置存 max_workers
- **坑：NVENC 会被其他进程占 GPU session**——当时有一个残留 ffmpeg.exe 占着，NVENC 全失败"Could not open encoder"，回退机制救场；等该进程结束 NVENC 自动恢复 6.3x
- 验证：NVENC被占时自动选 libx264+并发8（1.7x 实测）；产物分辨率/元数据/时间戳全 OK；并发中断正常；workers_spin 范围 bug 已修（0~16）
- 已提交推送：c35be86

## V10: SAR 修复（千川"尺寸不符合规范"）
- 用户反馈：裂变后视频上传千川报"素材尺寸（高度）不符合规范"
- 实测 D:\千川素材\M810\M810 千川素材 0806：40 个 1080x1920 + 30 个 1440x2560，**比例全 9:16 一致**（不是比例问题！）
- 对比源素材（2160x3840，SAR=1:1, DAR=9:16）→ **裂变产物 SAR=2943:2944（非1:1）、DAR=26487:47104（偏离精确9:16）**
- 根因：scale 滤镜非整数倍放大（1%）时 ffmpeg 自动调整 SAR 保持 DAR，crop 后 SAR 未还原
- 修复：`_build_filter` 滤镜链末尾加 **`setsar=1`**（SAR 锁死 1:1 → DAR 恒等于像素比）
- 验证：1080x1920 测试视频裂变 3 份 → SAR=1:1、DAR=9:16 精确、分辨率不变 ✓
- **提醒用户**：已裂变的旧批（SAR 有偏差）需删除重裂；若 1440x2560 重裂后仍报错，可能需统一转 1080x1920
- 已提交推送：69accb0

## 抖音商品链接（v.douyin.com 短链）下载分析
- 需求：分析 https://v.douyin.com/vSICx31j87I/ 这类「商品链接」的视频下载方式
- **关键结论：这不是普通抖音视频链接，而是抖店商品详情页（电商商品卡）**——302 跳转到 `haohuo.jinritemai.com/ecommerce/trade/detail/index.html?product_id=3831876835684254149`；商品 ID 从 302 Location 的 `product_id=` 参数提取；商品标题等也从 `goods_detail` URL 参数里能看到
- **强风控**：抖店 H5 对无登录环境一律拦"请使用抖音APP扫码 / 检测到当前环境存在安全风险"——headless Chrome、headful Chrome 独立 profile、先访问抖音主站拿 cookie 再进商品页，全部被拦；数据接口（`haohuo.snssdk.com/views/product/ajaxitem?id={pid}` 返回 200+空串）需登录态 cookie + 签名
- 页面是 PIA/Gecko 框架 JS 渲染壳，无 SSR 初始数据；`ecom.ecombdapi.com/aweme/v2/shop` 是电商 API 基址
- 实用下载路径：① 电脑 Chrome 登录抖音→打开商品页→F12 Network 过滤 Media→播放视频→复制 mp4 直链下载（免费）；② 第三方工具（星优图片下载助手等，选"抖店-主图视频"）；③ 抖店开放平台 API（需企业资质）；④ 手机 App 录屏兜底
- 调试技巧记录：本机 Chrome CDP 自动化（`chrome.exe --remote-debugging-port=9223 "--remote-allow-origins=*" --user-data-dir=...` + Python websocket-client 发 Runtime.evaluate）；`--remote-allow-origins=*` 必须加引号否则 bash 吞 `*`；Playwright MCP 浏览器被占时用此法兜底
