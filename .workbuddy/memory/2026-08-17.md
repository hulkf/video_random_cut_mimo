## 视频拼接 ffmpeg 8.1 抽帧失败修复

- **问题**：视频拼接 tab 拼接视频报错，根因在 `core/video_concatenator.py` 的 `_extract_cover_frame` 方法
- **三个独立根因**：
  1. ffmpeg 8.x image2 muxer 单文件名需显式 `-update 1`，否则边界场景触发 "At least one output file must be specified"
  2. `-ss` 浮点接近 duration 时报 "No filtered frames"，留 0.5s 余量
  3. ffmpeg 8.x `strict_std_compliance` 提高，mjpeg 拒绝 TV-range YUV（`yuv420p(tv, bt709)`），需 `-strict unofficial`
- **修复**：加 `-update 1` + clamp timestamp（0.5s 余量）+ `-strict unofficial`
- **验证**：10 次 random 抽帧 0 失败 + 2/2 端到端拼接成功
